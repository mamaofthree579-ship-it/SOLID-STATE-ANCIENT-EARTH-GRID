# 🌐 Solid-State Ancient Earth-Grid Simulation Core (SS-AEGIC)

An open-source interactive Python & Streamlit environment built to evaluate ancient global architecture—including **Rapa Nui (Easter Island), Teotihuacán, Tikal, the Indus Valley, and Giza**—as functional, macro-scale engineering networks based on solid-state physics, geodetics, and trans-medium fluid dynamics.

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com
cd ss-aegic
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the App Locally
```bash
streamlit run app.py
```

## 🧠 Core Engineering Frameworks Modeled
* **Giza Piezocore Transduction:** Computes the mechanical-to-electrical transformation occurring when high-quartz granite chambers are compressed under gravitational load and struck by low-frequency seismic earth swells.
* **Quetzalcoatl Trans-Medium Vessel:** Evaluates hull drag and Froude length optimizations based on an adjustable multi-hull arrangement moving across an air-water fluid matrix.
* **Tikal Hydraulic Ram Engine:** Calculates the water-hammer pressure wave spikes produced when rain runoff is funneled under a high-mass limestone pyramid matrix.
* **Rapa Nui Concave Roadways:** Simulates the vector geometry and self-correcting gravitational balance torque utilized to safely walk massive stone columns upright.
